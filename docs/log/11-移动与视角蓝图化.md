用户决定不采用 EasyGas：公开使用证据不足，不希望以核心属性迁移引入该依赖。本轮继续把玩法执行迁到可读蓝图，现有原生 GAS 属性集保留，不要求用户立即系统学习 C++。

## 现在在哪里查看

打开 BP_Player，左侧函数列表：

- MoveFromInput：接受 Axis（Vector2D，二维向量）。先检查角色是否有有效 Controller；读取 Pawn 的 ControlRotation，只保留 Yaw（水平方向）。通过该旋转计算 Forward（前方）和 Right（右方），分别执行 Add Movement Input：前方乘 Axis.Y，右方乘 Axis.X。
- LookFromInput：接受同样的 Axis，将 X 交给 Add Controller Yaw Input（左右转向），将 Y 交给 Add Controller Pitch Input（上下转向）。不额外反转或缩放轴值，保持原输入配置。

两个函数只执行动作，不判断攻击、翻滚或收刀。原事件图的移动锁与取消分支继续决定是否调用移动函数；两条原移动执行入口、视角执行入口和 Axis 数据线逐条接回新调用。CurrentMoveInput、攻击转向通知、输入资产和 IMC 均未修改。

删除 Source/ProjectUnreal/BaseCharacter.h/.cpp 中原 Move2D、Look2D 声明及实现。其余 C++ 属性、GAS 查询、能力请求和命中等暂留。

## 怎么理解方向计算

只取 Yaw，是为了抬头低头时仍沿地面走。输入 Y 控制前后，输入 X 控制左右。这里使用的是 MathLibrary 根据旋转计算出的前/右向量，不是直接取角色当前朝向；因此移动方向仍跟随控制器/相机的水平方向。
