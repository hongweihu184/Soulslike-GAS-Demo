# 19：怪物武器命中与玩家扣血

用户授权：接通怪物伤害链路。保留独立 GA，复用玩家现有 GE 和标签，不新增 C++。

## 最终实现

- BP_Dummy 新增 BoxComponent `EnemyWeaponHitbox`，位于 Mesh 下，半尺寸 (70,45,100)，默认无碰撞、生成重叠事件。
- GA_EnemyAttack（InstancedPerActor）每次激活取得怪物组件；首次激活挂接 Mesh 的 `weapon_r`（SnapToTarget，继承0.7缩放），调用已有 RegisterWeaponCollision，并将 HitboxRegistered 设 true，避免重复绑定。同一能力实例后续激活复用注册。
- 注册后先 WaitGameplayEvent(Event.Montage.Attack.Hit)，再播放原单次蒙太奇。等待事件不是 OnlyTriggerOnce；由已有 BaseCharacter 每挥击名单按目标去重。
- 命中事件取 Payload.Target，仅等于 GetPlayerCharacter(0) 时施加共享 GE_Damage，Level1、Stacks1。当前 GE 为固定50伤害，未修改共享 GE，未来改它也会影响玩家攻击。
- AM_EnemyAttack 添加 EnemyHitWindow 通知轨道，复用 ANS_AttackWindow，0.30–0.65秒开启武器重叠判定。
- K2_OnEndAbility 重新取得当前 Avatar 并关闭武器判定，覆盖正常结束和取消。原 Completed/Interrupted/Cancelled→EndAbility 保留。
- 原行为树距离220、冷却5秒、追踪逻辑未改。220是允许发动距离，是否命中仍取决于武器实际扫到玩家，并非发动即扣血。
