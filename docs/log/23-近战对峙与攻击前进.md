# 近战对峙与攻击前进（2026-10-23）

用户反馈怪物快速跑到玩家面前停住，提出有限转向和距离保持，并指出双方攻击缺少前进造成距离难判断。用户随后要求制定计划并实现。本轮按一对一最小交锋实施，未新增招式、侧移绕圈、无敌帧或受击系统。

## 最终行为

- 怪物450厘米外沿导航追击，保留原角色表速度；近处降至120厘米/秒。
- 145内开始后退，退到180停；200外开始靠近，到185停。进入/退出阈值分开，区间内允许站定。
- 最大转速180°/秒；攻击距离200、朝向容差15°。攻击任务等待条件满足才发动，不再直接设置朝向；出手后停止AI追踪转向，技能结束后仍冷却5秒。
- 玩家三段已有位移窗原速度均0，改100/100/125，窗口仍0.2–0.6秒；怪物新增0.1–0.35秒速度220的前进窗。
- 位移通知原先强转BP_Player，导致怪物虽有窗口却不位移；Tick改为共同BaseCharacter类型检查。保留Sweep，玩家翻滚原参数不动。

调参表、职责分工和后续限制见[设计与实施说明](../design/近战距离与对峙迭代.md)。控制器近处直接移动依赖碰撞；复杂绕障、多怪与后退动画还未验证。

## 验证与校准

首次计划采用220发动、200停步。真实距离网格100/140/160/180/200均造成一次25伤害，220挥空，另一次210也挥空，因此收紧发动至200、靠近停185，没有扩大用户配置的武器框。

最终临时PIE验证：

- 185距离站定；过近退至约185.5；350外靠近至约182.8；远处最大速度300。
- 绕背转身上限约180°/秒，从背向到合法朝向后才发动；攻击中目标换到身后，角色朝向保持。
- 两次攻击之间约5.63秒，包含5秒冷却与重新靠近/朝向等待。
- 玩家三段前进约48.8/50.3/59.3厘米，怪物约69.4。原通知首末帧会使实测超过名义40/40/50/55，保留此已知偏差，未实现精确距离累计。
- 怪物190距离单次造成25伤害；前摇取消后零伤害、零位移残留、碰撞框关闭及攻击标签清理。
- 玩家攻击碰到怪物胶囊后停止前进；真实翻滚仍前进约326厘米，确认共享通知兼容。
- 三个相关蓝图图表无编译错误，保存成功；重新加载行为树，攻击距离200和MoveTo半径450保留。

证据：`Saved/Spacing-RuntimeVerification.json`、`Spacing-ExtraVerification.json`、`Spacing-HitGrid.json`、`Spacing-PersistenceVerification.json`；公开精简归档在`docs/reproduction/spacing-validation-2026-10-23.json`。用户键鼠手感、脚步匹配尚未验收，不把脚本通过等同于体验通过。
