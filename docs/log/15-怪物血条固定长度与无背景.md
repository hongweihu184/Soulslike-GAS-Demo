# 怪物血条固定长度与无背景（2026-10-21）

用户要求怪物只显示当前红条与延迟白条，去掉两者背后的背景/边框；同时不论最大生命多少，怪物血条整条长度一致。当前血量百分比仍正常变化。这是怪物的信息表达规则，玩家继续通过整条长度表达容量。

## 变更

- WBP_ResourceBar 增加实例可编辑 UseFixedLength、FixedLength，分组 Appearance/Length。默认不启用固定长度，保留原 Clamp(MaxValue × LengthPerPoint, 0, MaxLength)；启用时直接使用 FixedLength，不再依赖 MaxValue、LengthPerPoint 或 MaxLength。
- PreConstruct 在固定模式下同步尺寸，支持设计器预览；UpdateResourceBar 持续按所选模式更新宽度，生命占比和拖尾逻辑保持原样。
- 增加实例可编辑 OverrideBackground（默认false）、BackgroundBrush，分组 Appearance/Background。启用覆盖时仅替换 PB_Trail.Style.BackgroundImage，保留当前 FillImage、MarqueeImage、EnableFillAnimation。默认关闭，避免改变玩家原背景或已有实例样式。
- WBP_EnemyHUD.HealthBar 启用固定长度200，并启用背景覆盖，画刷 DrawAs=NoDrawType、TintColor Alpha=0。检查时用户已将怪物 MaxLength 调为200，故固定长度沿用200。PB_Current 原背景Alpha已为0，无需改填充或隐藏整个控件。
- 本轮只修改并保存 WBP_ResourceBar、WBP_EnemyHUD。既有 BP_Dummy、WBP_HUD、地图外部Actor工作区修改保持不动；无Git提交推送，未更新快照。

## 验证

- 两份控件严格编译（warnings_as_errors）通过。
- PIE 临时属性分别设置最大生命50、100、500，当前生命各为一半；实际 WidthOverride 均200，CurrentPercent 均0.5。
- 读取运行时样式确认 PB_Trail 背景 NoDrawType、PB_Current 背景Alpha0，两个 FillImage 仍有绘制。
- 玩家运行时 HealthBar/StaminaBar.UseFixedLength=false，实际长度1200/800均符合各自原有容量比例及上限规则，背景仍为Box。
- 运行时回血后再掉血截图，确认头顶红条与延迟白条可见，白条后方没有底框。PIE 已停止，临时生命值不保存。
