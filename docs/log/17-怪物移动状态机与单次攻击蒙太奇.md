# 怪物移动状态机与单次攻击蒙太奇（2026-10-22）

用户授权通过 MCP 制作怪物基础动画并生成一次攻击蒙太奇；黑板、行为树留给用户手动创建，以复习工作流。本轮不制作怪物 GA、AIController、黑板或行为树，也不接自动攻击和伤害结算。

## 已保存资产

- `/Game/Gameplay/Anims/Enemy/ABP_EnemyMelee`：复制玩家动画结构后改用超级兵骨架 `SK_Minion_Lane_Super`；删除空中状态、相关转换和 IsInAir。动画图为 `Locomotion → DefaultSlot → 输出姿势`。状态机入口进入 `Ground`，其中播放 BS_EnemyMove。
- `/Game/Gameplay/Anims/Enemy/BS_EnemyMove`：复制资源包超级兵的 Idle2Run_Super，保留原样本：Speed=0 为 Idle、420 为 Combat_Jog_Fwd_Alt、700 为 NonCombat_Jog_Fwd。横轴 Direction 固定0，纵轴接 Speed。保留资源原始采样速度，不代表已经完成脚步与移动速度的手感匹配。
- `/Game/Gameplay/Anims/Enemy/AM_EnemyAttack`：超级兵 Attack_A_Dusk，约1.1秒，单段、循环次数1、播放倍率1，DefaultSlot，自动混出。未添加玩家三连击或命中/位移/转向通知。
- BP_Dummy 的 Mesh 动画类指定为 ABP_EnemyMelee。关卡已放置实例原来显式覆盖为空，另同步该实例并单独保存外部 Actor 包，避免类默认值正确但关卡里仍不播放。

事件图每次 BlueprintUpdateAnimation：检查 TryGetPawnOwner 有效 → 读取该 Pawn 的 Velocity → VectorLengthXY → 设置 Speed。有效性检查避免编辑器预览没有 Pawn 时访问空目标。

## 工具与验证

MCP 的动画图接口存在两个限制：删除动画状态节点时内部只接受 K2Node；在状态子图创建节点时，工具会把 AnimStateNode 错误转成 Blueprint。因此配合 Unreal 官方、仅绑定127.0.0.1的 Python 远程接口，使用原生 BlueprintEditorLibrary.remove_graph 与 BlueprintGraphEditor 创建/清理动画图。未改引擎文件或增加C++；临时远程连接设置用完恢复关闭。

ABP_EnemyMelee 与 BP_Dummy 严格编译通过。PIE 验证真实关卡怪物取得 ABP_EnemyMelee_C，单次蒙太奇启动、播放中、自然退出通过。实际移动测试仅临时调整运行实例的移动参数并注入200速度，检查位移、速度更新及停止归零；退出PIE后恢复资产参数。证据：Saved/EnemyAnimation-RuntimeVerification.json、Saved/EnemyAnimation-MoveVerification.json。未进行用户键鼠战斗验收，未验证命中伤害或AI追击。

修改前 BP_Dummy 和对应关卡外部 Actor 备份：LocalBackups/EnemyAnimation-2026-10-22。仅保存本轮指定资产，不做全工程保存、Git提交推送或公开快照同步。

## 后续接入与共用规则建议

用户提出玩家与怪物共用GE/标签、分别实现GA。助手赞同作为当前工程方案：通用伤害、资源与状态效果共用；差异值后续通过来源属性或SetByCaller传入。静态写死数值的同一GE会影响双方，不能把“共享GE”理解成已经支持不同伤害值。标签按语义共用，如State.Attacking；每个角色ASC独立持有标签，不会因为玩家攻击而给怪物也挂上攻击状态。

怪物后续独立 GA_EnemyAttack 负责播放 AM_EnemyAttack、命中事件和技能结束；不能直接套用玩家三连击窗口或体力门槛。行为树负责何时请求攻击、GA负责完成动作并结束，具体等待结束和失败处理留到用户复习行为树时接入。当前只生成蒙太奇，没有生成可造成伤害的怪物攻击能力。
