# 怪物头顶血条（2026-10-21）

用户授权使用 MCP 检查 WBP_ResourceBar 并为怪物接入血条，同时讨论伤害跳字与怪物 HUD 的职责。

## 实现

- 新增 Gameplay/WBP/WBP_EnemyHUD，复用现有 HealthBar（WBP_ResourceBar 实例）。从玩家 HUD 复制后移除玩家引用及体力更新接线；复制的 StaminaBar 设计器控件保持 Collapsed，不参与更新。
- HUD 的 TargetActor 指向所属怪物，每帧通过 GetFloatAttribute 读取 MyAttributeSet.Health/MaxHealth，再调用 UpdateResourceBar；不修改原资源条拖尾实现。
- 首次同步记录生命值并保持透明；后续生命值下降时设置显示截止时间。普通掉血保持4秒，归零保持1秒，再次掉血刷新截止时间。TargetActor 无效时透明。使用 RenderOpacity 隐藏，保留 Tick 以便后续受伤重新显示。
- VisibleDuration、DeathVisibleDuration 为可编辑参数。怪物实例血条最大长度180，LengthPerPoint=1.8，沿用红色；通过实例纵向渲染缩放0.4缩薄，不改公用资源条。
- BP_Dummy 添加 EnemyHUD Widget Component。首次 Tick 设置屏幕空间、DrawSize=(220,40)、相对高度125，显式 CreateWidget、SetWidget、TargetActor=self，并保存 EnemyHUDInstance、置 EnemyHUDBound=true；之后只经过初始化标记判断，不重复创建。沿用原有父类 BeginPlay 初始化。

## 验证与工具限制

- 两份蓝图 warnings_as_errors 编译通过并保存。
- PIE 验证所属怪物引用正确、初始化 Health=100 / MaxHealth=100、血条占比1、透明度0。
- 仅在 PIE 临时属性上修改 Health：100→75 后占比0.75、拖尾1、透明度1；75→60 后刷新截止时间；等待后透明度0且拖尾追至0.6；60→0 后先显示，随后隐藏。
- 实际编辑器截图确认头顶出现红色血条。完整攻击伤害链路、怪物死亡行为、遮挡及多人情形未测试；不将 UI 归零隐藏记为怪物死亡系统完成。
- 新增组件后，已有场景怪物保留了组件最初的空 WidgetClass/World 空间，而临时新放置实例正确继承模板。官方 save_actor 对外部 Actor 包调用 AssetTools.exists 失败；最终采用显式运行时初始化，避免依赖关卡实例保存来保证血条工作。
- PIE 已停止，测试生命值不写入角色资产。原 WBP_HUD、WBP_ResourceBar、C++ 未修改。没有提交、推送或更新 ProjectContentSnapshot。

## 伤害跳字讨论

建议独立 WBP_DamageNumber，由伤害结算事件传入伤害值、出现位置和伤害类别，播放短暂上浮/淡出。每次有效伤害一个数字，位置略错开；数字可在怪物血条隐藏后继续播放。不要以两帧生命差作为最终跳字来源，避免同帧多次伤害合并或回复混入。伤害值采用结算结果还是实际扣除生命（尤其过量伤害）仍需与用户定案。跳字尚未实现。
