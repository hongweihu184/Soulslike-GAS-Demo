# 22：玩家与怪物零血死亡销毁

用户要求：怪物或玩家生命为0时死亡销毁。新增玩法全在蓝图，无C++、GE、DamageID表和蒙太奇改动。

## 实现

共同父类BP_CombatCharacter新增IsDead（默认false）、DeathHealthObserver，以及CheckForDeath/HandleDeath/StopDeathHealthObserver。

BeginPlay保留原InitializeStatsFromTable和体力回复GE，完成后WaitforAttributeChanged监听Health（非单次），保存Async代理并执行一次初始死亡检查。属性变化只调用CheckForDeath，不用Tick轮询；出生初始化中的上限/当前属性临时变化不会误触发。

CheckForDeath读取原GetHealthPercent，<=0则HandleDeath；HandleDeath用IsDead保证只执行一次，按顺序：

1. 标记死亡。
2. EndConfiguredDamageWindow关闭本轮所有攻击框。
3. CancelAttack取消攻击GA。
4. CharacterMovement.DisableMovement。
5. SetActorEnableCollision(false)。
6. EndAction停止死亡生命监听。
7. Controller有效且有BrainComponent时StopLogic；玩家没有Brain仍继续。
8. SetLifeSpan(0.01)，让当前GAS伤害与属性广播先完成，再在下一帧销毁Actor。没有死亡动作、尸体或重生机制。

父类ReceiveDestroyed也调用StopDeathHealthObserver，覆盖直接销毁角色的清理。Pawn正常销毁自动脱离控制器，怪物AIController也随之销毁，玩家PlayerController保留。
