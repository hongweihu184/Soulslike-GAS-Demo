```text

├─ TargetActor 有效：行动周期 Sequence

│  ├─ DSDecide：按原优先级构建权重，过滤3003冷却，只抽取一次行动
│  ├─ Dispatch Selector（Selected Action）
│  │  ├─ 01/02：配置走/跑接近 → 原生MoveTo → 选两/三段 → 逐段攻击

│  │  ├─ 11：必要时接近 → 限时后退
│  │  ├─ 12：限时侧移，带原分支的范围退出条件
│  │  ├─ 13：原生有限转向，最多3秒，角度门槛随机15～20
│  │  ├─ 20/21：特殊变体的动作分支（实际效果尚为近战替代）
│  │  └─ 54：110054变体的单独接近分支
```

原生 MoveTo 负责主要接近。DSRelativeMove 在执行当前侧移/后退时，以0.2秒间隔刷新导航目标，并等待距离、持续时间或转身条件完成；这些 Tick 不选择新行动。没有复用旧400/550交战圈、140→200/190→150警戒循环或统一5秒攻击冷却。

## 与源脚本对应的逻辑

- 普通正面远/中/近距离权重、侧后方向优先级，按已验证的110050脚本构建。
- TeamRole、EventRequest1、ThinkParamID 特例有独立输入分支；144040的低血量触发与未触发时额外权重、144041、110054均有对应逻辑。
- 仅3003通过攻击历史过滤20秒冷却；其他动作不被该冷却一起封锁。初始化时将未攻击历史视为可用，是尚未确认原生默认值时的原型选择。
- Approach_Act_Flex 的普通动作走/跑门槛、4秒步行/8秒跑步准备预算已映射；20/21包含中间距离50%跑近及远处强制跑近。AddDistWalk/Run在已读取的初始化辅助函数中为0。
- Act01/02一次抽取25%两段、75%三段，选中后持续执行该套行动；不是每帧重抽。
- 普通攻击50%进入攻击后调整，特殊20/21为100%，11/12/13等移动行动不进入。随后按原距离区间选择调整，不加统一等待时间。末端的0秒Wait只用于完成BT选择器，不是人为的战斗冷却。
- 当前动作中止时清理导航与攻击GA。目标失效可中止整周期；Act12近距离侧移超过5.5单位时结束当前移动并重新决策。

源脚本及权重表见 [断剑行为树反推](../research/06-黑魂3断剑敌人行为树反推.md)。补充读取了 `common_func_FDP.lua` 中的 Approach_Act_Flex、SetCoolTime、InsideRange 和 Init_Pseudo_Global；该辅助文件尚未新增独立往返验证，不将读取结果扩展为原生引擎的完整正确性证明。
