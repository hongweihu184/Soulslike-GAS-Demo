# 近战距离与对峙迭代（2026-10-23）

用户反馈：怪物快速跑到玩家面前停住；双方攻击缺少可感知的前进，攻击距离难以判断。用户授权制定计划并实现。

## 本轮计划

1. 备份并读取当前蓝图、行为树、攻击蒙太奇和位移通知；以实际保存配置为准。
2. 怪物冷却期间改为距离区间控制：远处寻路追击，近处慢速靠近，过近后退，合适距离站定。使用不同的进入/退出阈值避免边界抖动。
3. 对峙朝向受最大角速度限制；发动攻击同时检查距离与朝向，移除攻击开始时的瞬间转身。出手后固定方向，允许侧闪和绕背。
4. 复用蒙太奇位移窗口，为玩家三段普攻和怪物单招配置短距离前进；碰撞 Sweep 保留，不改武器框、伤害和攻击窗口。
5. 编译、保存、重新读取并进行运行验证，检查追击、冷却、后退、有限转向、攻击位移、取消清理与命中；记录实现参数和证据。

## 初始体验目标

- 玩家主动靠近后，普攻具有适量前进，不必精确踩住极窄距离。
- 怪物靠近后不挤住玩家，也不持续前后抖动；玩家绕背时需要时间转身。
- 冷却结束只代表可出招，距离和朝向仍需满足；攻击开始后不能瞬转追踪。
- 保留攻击结束后5秒冷却；本轮不增加绕圈、多招式、无敌帧或新受击系统。

所有距离为水平胶囊中心距离，单位厘米。初始参数是待试玩的设计假设，不作为手感验收结论。最终实现与验证在完成后补记。

## 已实现的初版

| 调整项 | 最终配置 / 调整位置 |
|---|---|
| 近身速度 | BP_EnemyAIController 类默认值 CombatMoveSpeed=120 cm/s |
| 最大转速 | CombatTurnRate=180°/s |
| 过近后退 | RetreatEnterDistance=145；后退到 RetreatStopDistance=180 后停步 |
| 靠近与停步 | ApproachEnterDistance=200；靠近到 ApproachStopDistance=185 后停步 |
| 远处追击 | ChaseDistance=450；缓存角色原 MaxWalkSpeed，本次实测为300，不覆盖原速度表 |
| 攻击发动 | BT_EnemyMeleeCombat 的距离装饰器=200；BTT_EnemyAttack 的 AttackStartDistance=200、AttackFacingTolerance=15° |
| 攻击冷却 | 保留原行为树 Cooldown=5秒，从攻击任务完成后计算 |
| 玩家攻击前进 | 三个原位移窗保持0.20–0.60秒；LungeSpeed=100/100/125，名义40/40/50 cm |
| 怪物攻击前进 | AM_EnemyAttack 新增 AttackAdvance 轨道，0.10–0.35秒，LungeSpeed=220，名义55 cm |

`ANS_AttackLungeWindow.Received_NotifyTick` 原来只允许 BP_Player，已将该类型检查扩展到共同 C++ 父类 BaseCharacter。Sweep 保留。原翻滚与玩家通知继续复用，未改位移计算或翻滚参数。攻击位移朝角色前方执行，没有目标吸附。

控制器读取原黑板 Key Name 指定的 TargetActor；Tick 在 State.Attacking / State.MoveLocked 存在时让出控制。近处停止寻路，用移动输入靠近或后退；区间内站定。远处沿导航追踪，路径请求间隔0.4秒。原行为树 MoveTo 的停靠半径相应调整为450，负责远处追踪，近处交给控制器。修改 ChaseDistance 时须同步该 MoveTo 半径。

攻击任务不再瞬间设置角色朝向。任务进入后先等待距离、朝向都合法，之后停导航、清移动速度并发动 GA 一次；攻击标签退出才完成任务。玩家跑远时，等待阶段仍由控制器追踪，不提前启动攻击冷却。攻击过程中停止 AI 转向，取消仍沿原 CancelAttack 链路清理。

## 校准依据与验证边界

原玩家三段位移窗口速度实际均为0。首版怪物220发动、近身停200；距离网格测试100/140/160/180/200均命中一次25伤害，220挥空，另一次210也挥空。最终收紧发动距离为200，靠近停185；没有扩大用户武器框或改变伤害窗来补偿。

最终运行测试通过：区间站定185、过近后退约185.5、远处靠近约182.8厘米；角速度上限约180°/s；远处速度300；转身后符合15°朝向与200距离才攻击；出手后不跟随玩家绕背旋转；两次攻击间隔约5.63秒。玩家三段实测约48.8/50.3/59.3 cm，怪物约69.4 cm。沿用原通知按帧位移，通知首末帧会带来与名义距离的偏差，本轮没有引入精确距离累计器。

运行证据见 Saved/Spacing-RuntimeVerification.json，补充命中/取消/碰撞/翻滚检查见 Saved/Spacing-ExtraVerification.json。位置调整只发生在临时试玩实例，未保存测试关卡。动画仍使用当前素材，未新增后退/侧移动作；近处移动依赖碰撞，尚未做复杂障碍、多怪或键鼠手感验收。下一步由用户试玩评估距离和步伐匹配。
