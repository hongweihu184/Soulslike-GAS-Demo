使用铁律(素材管理的五条规矩)

  1. Paragon 包内的资产:只引用,不移动、不改名、不复制。官方目录结构保持原样,升级/换素材/别人接手时不混乱。
  2. 我们创建的资产一律放自己的目录(Content/Gameplay/、以后的 Content/Maps/ 等),和 Paragon 包泾渭分明。
  3. 引用骨骼网格时认准 Meshes/ 里的主资产(如 Greystone.uasset),不要选 Skeleton(纯骨架)或 PhysicsAsset(物理资产)。
  4. 动画文件名后缀:_Montage = 已打包好的蒙太奇(可直接用);_MSA = Motion Matching 用的姿势库(本项目不用);无后缀 = 普通动画序列(要自己组蒙太奇)。
  5. Paragon 自带的 xxPlayerCharacter.uasset / xx_AnimBlueprint.uasset 是参考对象(抄配置),不直接当游戏角色用——我们的角色体系是 GAS 的 BaseCharacter。

Greystone(主角)⭐

根目录:Content/ParagonGreystone/Characters/Heroes/Greystone/

Greystone/
├── Meshes/
│   ├── Greystone.uasset               ← 骨骼网格本体(已在 BP_BaseCharacter 引用)
│   ├── Greystone_Skeleton.uasset      ← 骨架(纯骨骼,别当模型选)
│   └── Greystone_PhysicsAsset.uasset  ← 物理资产(布娃娃用)
├── Animations/                        ← 145 个动画,分类见下表
│   └── AimOffsets/                    ← 瞄准偏移(锁定姿态用,第 7 章)
├── Materials/ Textures/ Skins/        ← 材质贴图皮肤
├── Greystone_AnimBlueprint.uasset     ← 官方动画蓝图(第 3 章评估参考)
├── GreystonePlayerCharacter.uasset    ← 官方角色蓝图(配置参考对象)
└── AnimationTestMap.umap              ← 官方动画预览图(可打开看全部动画效果)

Grux(Boss)⭐

根目录:Content/ParagonGrux/Characters/Heroes/Grux/(内部结构与 Greystone 相同)

  • 网格:Meshes/Grux.uasset
  • 招式动画候选(第 10 章 Boss 招式的原材料):Attack_Melee_Air、Cast、DoublePain(疑似招牌连击)、Gruxx_Ultimate_Noise_Additive、Emote_Master_BattleCry_T3(吼叫,可作转阶段演出)
  • 受击/死亡:HitReact_Front/Back/Left/Right、Death_A、Death_B(两种死亡,可作阶段演出)
  • 移动:Idle、Jog_* 系列、Blendspaces/(官方配好的移动混合空间)
  • 音效:Sounds/(Boss 战吼叫、打击音,第 10/11 章)
  • 官方参考:Grux_AnimBlueprint、GruxPlayerCharacter、AnimationTestMap
